# Complex Hadamard matrices of order (q + 1)/2 from Paley's matrix

**Theorem.** For every prime power q ≡ 3 (mod 4) there is a quaternary (complex) Hadamard matrix of order (q + 1)/2.

For q ≡ 3 (mod 8) the order is 2N with N = (q + 1)/4 odd. So every order 2N with N odd and 4N − 1 a prime power is
settled. Among the odd N < 1000 the theorem settles 63 values that were open. These are the orders 406, 414, 474,
526, 546, 582, 646, 666 and 55 more up to 1966; the list is below. It also gives the 13 orders 142, 154, 222, 262,
286, 310, 322, 330, 342, 370, 430, 454 and 742, which this repository had first constructed by searches.

## Proof

Let q ≡ 3 (mod 4) be a prime power, χ the quadratic character of GF(q) with χ(0) = 0, and note χ(−1) = −1.

**Paley's matrix.** Index the q + 1 points of the projective line PG(1, q) by representatives: u_x = (x, 1) for
x ∈ GF(q) and u_∞ = (1, 0). Put S[a, b] = χ(det(u_a, u_b)). Then S[x, y] = χ(x − y), S[∞, y] = 1 and S[x, ∞] = −1, so
S is Paley's skew conference matrix: Sᵀ = −S and S Sᵀ = q I. Hence H = I + S is Paley's skew Hadamard matrix of
order q + 1: H Hᵀ = I − S² = (q + 1) I.

**A monomial action of SL(2, q).** Let g ∈ SL(2, q). It maps each representative to a multiple of a representative,
g u_a = λ_a u_(g(a)) with λ_a ∈ GF(q)*. Since det(g u, g v) = det(u, v),

    S[g(a), g(b)] = χ(λ_a)⁻¹ χ(λ_b)⁻¹ S[a, b] = χ(λ_a) χ(λ_b) S[a, b].

So the signed permutation matrix P_g, defined by P_g e_a = χ(λ_a) e_(g(a)), satisfies P_g S P_gᵀ = S. It is
orthogonal and fixes I, so it commutes with H. The map g ↦ P_g is a homomorphism. For g = −I every λ_a equals −1, so
P_(−I) = χ(−1) I = −I.

**An element of order 4.** Take g = [[0, 1], [−1, 0]], which acts by u ↦ −1/u. Then g² = −I, so P_g² = −I. The
underlying permutation is an involution without fixed points, since −1 is not a square in GF(q). It pairs x with
−1/x and 0 with ∞.

For each pair choose one point f. The vectors e_f together with P_g e_f form an orthonormal basis of signed unit
vectors. In this basis P_g = [[0, −I], [I, 0]]. A matrix that commutes with it has the form [[A, B], [−B, A]], so in
this basis

    H = [[A, B], [−B, A]],

with A and B ±1 matrices of order m = (q + 1)/2. H Hᵀ = (q + 1) I gives A Aᵀ + B Bᵀ = (q + 1) I and A Bᵀ = B Aᵀ.

**The complex matrix.** K = (A + iB)/(1 + i) has entries ((a + b) + i(b − a))/2 ∈ {±1, ±i} for a, b = ±1. It satisfies

    K K* = (A Aᵀ + B Bᵀ + i (B Aᵀ − A Bᵀ))/2 = m I. ∎

The last step is the classical half-order lemma: a Hadamard matrix of order 4t of the form [[A, B], [−B, A]] gives a
complex Hadamard matrix of order 2t (Seberry and Yamada 1992, Lemma 11.16, after Miyamoto; Turyn had an analogous
result). What the proof adds is that Paley's matrix has this form. The form comes from an element of order 4 in
SL(2, q) whose square acts as −I.

In coordinates, with f_1, ..., f_m the chosen points and P_g e_f = s_f e_(g(f)),

    K[k, l] = (H[f_k, f_l] + i s_(f_l) H[f_k, g(f_l)]) / (1 + i).

**Remarks.**
- For q ≡ 7 (mod 8) the order (q + 1)/2 is divisible by 4. Quaternary Hadamard matrices of such orders already come
  from real Hadamard matrices, so the theorem adds nothing there.
- The Sylow 2-subgroups of SL(2, q) are generalised quaternion. When q ≡ 3 (mod 8), the quaternion group generated by
  g and h = [[a, b], [b, −a]] (with a² + b² = −1) acts semiregularly on the q + 1 points modulo its centre. So Paley's
  matrix is equivalent to a Williamson array of four ±1 blocks of odd order (q + 1)/4. These blocks satisfy the
  relations of the array; they need not be pairwise amicable.

## Certificates and verification

Each certificate `C<order>.json` (construction `paley`) gives q = p^k. For k > 1 it also gives the modulus `poly`
(coefficients c_0, …, c_(k−1), 1, the first monic irreducible polynomial in lexicographic order of which t is a
primitive root), and it records the SHA-256 of the canonical text of K.

    python3 search/paley_complex.py build 811           # builds the matrix of order 406 and checks K K* = 406 I exactly
    python3 search/paley_complex.py certify 811         # writes complex-hadamard/C406.json
    python3 verify/verify_complex.py 406 666            # rebuilds with separate field arithmetic and checks

`verify_complex.py` builds GF(q) by polynomial multiplication: it finds the squares directly and computes inverses by
exponentiation, and it shares no code with `search/paley_complex.py`. It then checks every entry and K K* = n I in
integer arithmetic, and compares the digest. Both programs give the same digests for all 63 orders.

## Novelty

Both ingredients are classical:
- the automorphism group of Paley's matrix, which contains this monomial action of SL(2, q) (Kantor 1969);
- the half-order lemma (Turyn 1970; Miyamoto 1991; Seberry and Yamada 1992, Lemma 11.16).

We found no statement that combines them, and three sources show that it was not in use:
- Seberry and Yamada's Table 11.2 (1992) leaves all these orders blank. Among them is 70 (q = 139), which Đoković
  then obtained from good matrices in 1993. Their key wh for Williamson-type matrices assumes, as a hypothesis, that
  (p + 1)/4 is an order of Williamson-type matrices for p ≡ 3 (mod 4).
- Szöllősi (arXiv:2603.09572, 2026) credits order 70 to Đoković's good matrices.
- Kharaghani, Mohammadian and Tayfeh-Rezaie (arXiv:2605.08661v2, 2026) take the smallest unresolved order, 118,
  from the 1992 table and construct orders only from near-Williamson matrices.

There is related literature we could not read: Hadamard matrices of (generalised) quaternion type (Ito 1981;
Discrete Math. 1991), Ito's Hadamard groups, the chapter on Hadamard matrices in the Handbook of Combinatorial Designs
(Craigen and Kharaghani, 2007), and the 2020 edition of Seberry and Yamada's book. Paley's matrices
appear in all three. Because every step here is classical, specialists may regard the construction as known. We
label the orders New in the sense of [NOVELTY.md](../NOVELTY.md): blank in the reference table, and no later
construction found.
