# Order 2148

2148 = 4 · 537, with 537 = 3 · 179.

## Status

Open. After 2060 and 2092, this is the smallest order we know to be unresolved. The
entry 537(3) is unresolved in Cati–Pasechnik Table 4 and is not covered by
Đoković's updates.

## Notes

None of the following routes is within reach:

- **Goethals–Seidel over ℤ₅₃₇.** The multiplier group ℤ₅₃₇* ≅ ℤ₂ × ℤ₁₇₈ has no
  subgroup that gives admissible row sums together with a moderate number of orbits.
- **Spence's bordered construction over groups of order 536.** Several structures have
  admissible row sums. The best one, ℤ₈ × ℤ₆₇ with a multiplier subgroup of order 11,
  has a predicted search cost of order 10²² operations.
- **Cooper–Wallis with Williamson matrices of order 3.** This needs T-matrices of
  order 179. They are not known, and ℤ₁₇₉* has no useful multiplier subgroup.

A new idea is needed for this order.
