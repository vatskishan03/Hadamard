# Order 4412

4412 = 4 · 1103, with 1103 prime.

## Status

Open, and out of reach for the present method.

## Target structure

- Goethals–Seidel over ℤ₁₁₀₃.
- Sequences constant on the cosets of the multiplier subgroup ⟨17⟩ of order 19:
  59 orbits and 29 autocorrelation classes.
- Row sums (1, 37, 39, 39).

This is the only multiplier structure for 1103 with admissible row sums.

A pilot with lists of 4.5 · 10⁷ candidates per row sum measured about 10⁻⁹
expected solutions per partial sum τ. Extrapolated to lists of 10⁹, that is
months of matching on one machine. The structure has 58 cosets, as at order
2092, but the class values spread twice as much (variance grows with p). Over
28 independent classes that costs several orders of magnitude.

The entry 1103(3) is unresolved in Cati–Pasechnik Table 4 and is not covered by
Đoković's updates.
